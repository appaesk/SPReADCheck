Research Plan mode accepts one Excel file. Application Form mode accepts one or more PDF files.

The browser stores the files only in memory while the check runs. Nothing is sent to a backend server.

How this works

  • GitHub Pages serves this as a static site.
  • Pyodide loads Python in the browser and installs the needed packages.
  • The existing checker scripts are fetched into the browser file system and executed there.
  • The result workbook is generated in memory and offered as a download.
